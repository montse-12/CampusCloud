# CampusCloud - Persistencia Poliglota NoSQL (Unidad II)

Arquitectura NoSQL desplegada con Docker Compose:
- **MongoDB (`27018`)**: Catalogo documental (`detalles_servicios`).
- **Neo4j (`7474` / `7687`)**: Grafo de dependencias y recomendaciones.
- **ScyllaDB (`9042`)**: Telemetria de series temporales (`metricas_servicios` y `bitacora_accesos`).
